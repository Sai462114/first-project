# Student Management System (Java)

A beginner-friendly, console-based Java project demonstrating object-oriented programming and basic CRUD operations.

## Features
- Add a student with a name and course
- View all students
- Search for a student by ID
- Update student details
- Delete a student
- Input validation for student IDs and names

## Technologies
- Java
- ArrayList and collections
- Classes, objects, encapsulation, and methods
- Scanner for console input

## Requirements
- JDK 17 or later

## Run the project
From the repository root:

```bash
javac src/Main.java
java -cp src Main
```

## Menu
1. Add student
2. View all students
3. Search student by ID
4. Update student
5. Delete student
0. Exit
